水月的图片展示工具（Windows，可选）

这个工具能做什么
让水月在身边展示一张你准备的图片，停留几秒后收起。
例如，你放入几张表情包，运行工具后，水月会随机展示其中一张。
走路、跑步、跳跃、睡觉和点击表情在导入皮肤后就能使用。

第一次使用
1. 先在 Coopanion 中导入皮肤并选择「水月」，保持应用运行。
2. 找到已经安装的水月皮肤文件夹，打开里面的 tools 文件夹。
   形象包安装在 Coopanion 数据目录的 figures 文件夹下。
   数据目录由你的安装方式决定，可以在 Coopanion 设置中查看数据存储位置。
   如果手动安装过皮肤，就从你放入 mizuki 的那个文件夹打开。
3. 双击 media.cmd。
4. 工具会打开 Coopanion 安装目录和用于放图片的素材目录。
   把 PNG 或 JPG 图片放进素材目录，再双击一次 media.cmd。
   水月会从中随机展示一张。素材目录为空时，会使用水月的缩略图演示。

tools 已随皮肤一起安装。请从已安装皮肤的 tools 文件夹运行，
这样工具生成的图片才能由正在使用的水月读取。

文件分别做什么
media.cmd —— 打开素材目录，并随机展示一张图片。
sync-moods.cmd —— 把按心情分类的图片交给水月，以后按表情自动展示。
make-shortcut.cmd —— 在桌面创建「水月-发送表情包」快捷方式。
media.ps1 —— 上面三个入口共用的程序。

按心情自动展示图片
先运行 media.cmd，在它打开的素材目录里建立以下任意子文件夹，
把相应图片放进去，然后双击 sync-moods.cmd。

happy       开心
love        喜欢
angry       生气
sad         难过
shy         害羞
surprised   惊讶
sleepy      困倦
excited     兴奋
thinking    思考
smug        得意
pout        嘟嘴
confused    疑惑或晕眩
neutral     通用

也支持中文文件夹名，例如「开心」「喜欢」「生气」「通用」。
同步后，水月会间隔一段时间自动展示符合当前心情的图片。
更换图片后，再运行一次 sync-moods.cmd 即可重新同步。

找不到目录或没有显示图片时
先确认 Coopanion 正在运行，并且当前形象已经切换成「水月」。
再确认运行的是已安装皮肤里的 tools，而非另一个解压目录中的副本。
工具窗口会显示找到的数据目录和结果，出现错误时可以据此定位。
图片推荐使用 PNG 或 JPG。
