# 水月 · Coopanion 皮肤 v1.2

![水月皮肤预览](mizuki/thumbs/mizuki.png)

明日方舟角色水月的非官方 Q 版桌宠皮肤，带有水母帽和浅蓝色头发，支持走跑、跳跃、睡觉与点击互动。

## v1.2 更新

- 优化了人物被拎起时的手部和腿部动作。
- 眼睛会微微跟随鼠标移动。
- 抚摸时会冒爱心。
- 优化了人物被甩动时的惯性。

## 安装

1. 打开 [Releases](https://github.com/Hzzzz234/coopanion-skin-mizuki/releases/tag/v1.2)，下载 **mizuki-v1.2.zip**。
2. 打开 Coopanion 的 **装扮 → 导入**，选中下载的 ZIP。
3. 导入后，选择「水月」。

更新后请先切换到其他形象，等它显示后再切回水月；若动作仍未更新，请完全退出 Coopanion 后重新打开。

也可以把解压后的 `mizuki` 文件夹放进 Coopanion 数据目录的 `figures` 下。启动后刷新形象列表即可。 [Coopanion 形象包指南](https://coo.palailab.org/guide/make-figure/)

## 动作与表情

- 微侧身走路，前倾跑步。跳跃时手脚会轻摆。
- 坐下闭眼打盹。被拎起时轻摆，轻放后恢复待机，重摔后坐地眩晕。
- 被拎起时，手臂和手上下轻晃，小腿带着鞋子左右摆动。
- 醒着且未晕眩时，将鼠标在头部来回移动一次，可以抚摸水月并触发爱心表情。
- 连续点击会触发惊讶、爱心眼、闭眼笑或半睁眼不满等反应。不满时身体会短促地抖一下。

![惊讶、爱心眼、开心和不满四种表情](assets/expressions.png)

形象包采用 Coopanion API 2。Windows 可选贴纸工具见[包内说明](mizuki/tools/README.txt)。
