# 水月 · Coopanion 皮肤 v1.1

![水月皮肤预览](mizuki-v3/thumbs/mizuki.png)

明日方舟角色水月的非官方 Q 版桌宠皮肤，带有水母帽和浅蓝色头发，支持走跑、跳跃、睡觉与点击互动。

## 安装

1. 在仓库首页选择 **Code → Download ZIP**。
2. 打开 Coopanion 的 **装扮 → 导入**，选中下载的 ZIP。
3. 导入后，选择「水月」。

也可以把解压后的 `mizuki-v3` 文件夹放进 Coopanion 数据目录的 `figures` 下。启动后刷新形象列表即可。 [Coopanion 形象包指南](https://coo.palailab.org/guide/make-figure/)

## 动作与表情

- 微侧身走路，前倾跑步。跳跃时手脚会轻摆。
- 坐下闭眼打盹。被拎起时轻摆，轻放后恢复待机，重摔后坐地眩晕。
- 连续点击会触发惊讶、爱心眼、闭眼笑或半睁眼不满等反应。不满时身体会短促地抖一下。

形象包采用 Coopanion API 2。Windows 可选贴纸工具见[包内说明](mizuki-v3/tools/README.txt)。
